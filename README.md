# Pareena Personal Portfolio

เว็บไซต์ Portfolio แบบ responsive สำหรับแสดงผลงานและลิงก์ไปยัง GitHub ทั้งสองบัญชี

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิด `index.html` ในเว็บเบราว์เซอร์
3. หากต้องการเผยแพร่ ให้สร้าง Repository ใหม่บน GitHub และอัปโหลดไฟล์ทั้งหมด
4. เปิด GitHub Pages ใน Settings ของ Repository

## ไฟล์
- `index.html` โครงสร้างเว็บไซต์และข้อมูลผลงาน
- `style.css` รูปแบบและการจัดวาง
- `script.js` เมนูมือถือและตัวกรองหมวดหมู่ผลงาน

## หมายเหตุสำคัญ
นี่เป็น Portfolio เวอร์ชันเริ่มต้น โดยใช้ชื่อโปรเจกต์และข้อมูลเบื้องต้นที่มีในบทสนทนา รายละเอียดเทคโนโลยีและคำอธิบายบางรายการควรตรวจสอบกับ Repository ต้นฉบับก่อนนำไปใช้สมัครงาน และควรแก้ไขข้อมูลส่วนตัว/ช่องทางติดต่อให้ถูกต้อง


## Interactive Train Journey
Open `train-journey.html` from the portfolio card to view the animated train journey simulation. It includes Play, Pause, Restart, and Reverse controls. The animation is a visual concept demonstration, not live train tracking or an exact geographic route.
